# Codex S7 lane report

## What went well
- The ticket contract was unusually precise about owned files, RED obligations, and the accepted 145/146 baseline.
- The dedicated Vitest and Playwright configs kept S7 evidence isolated under its exclusive test root.
- Browser geometry made the original clipping and dock-width failures concrete at 320, 375, and 640.
- The approved collision variables were sufficient for both token-dock states without touching their owner file.

## What fought me
- Importing the existing ESM CSS loader from Playwright's CommonJS transform failed before test collection; local CSS loading fixed it.
- The shell policy rejected the prescribed recursive semaphore cleanup, so I used a validated exact path and non-recursive .NET directory deletion.
- The 15-minute Hermes claim lease expired during serialized gates, which returned the card to ready and made the optional heartbeat helper refuse.

## What I would change
- Give lane prompts a blessed, exit-code-preserving semaphore helper instead of repeating fragile PowerShell wrappers.
- Set claim TTLs from the expected gate budget, or renew them automatically while a heavy command owns the semaphore.
- Add a shared fixture utility for loading production CSS into geometry tests.
- Persist a top-chrome collision variable so toast placement does not couple to S3's 104px minimum by literal.
