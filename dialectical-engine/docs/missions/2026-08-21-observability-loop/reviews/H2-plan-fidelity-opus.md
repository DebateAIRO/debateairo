### REG-01 — MINOR (non-blocking) — Two redaction MUSTs (OBS-R046, OBS-R047) lost their citations, and the RT-08 equal-work move relocated zone redaction off the capture path without arguing the OBS-R046 deviation

- **Section:** §A.7 (write path), §E.3 line 242 (equal-work), §B.1 line 104 (redactor export); §A.6.
- **What changed:** in round 0, redaction placement was an explicit MUST — "capture-time, synchronous redaction before any sink" citing `OBS-R046` — and the never-store list cited `OBS-R047`. Both ids are **uncited anywhere in round 1** (coverage map confirms). §E.3 line 242 now states that in `zoneBoundary` context "**no redaction** happens before the response is written … **all classification runs on the flusher, off-path**," and §A.7 line 92 describes `emit()`→queue→flusher without stating where redaction occurs on the general path. `OBS-R054`'s canary scope is narrowed in wording from the ruled "secrets in keys, values, messages, stacks, causes, URLs and provider output" to "identity-shaped canaries" (line 69).
- **Why it is only MINOR (substance verified preserved):** the protective invariant still holds by construction — the flusher is the sole writer to both durable sinks; a ZONE outcome stores a counter increment only (no message/stack ever reaches a sink); `OBS-R041` (still cited, lines 44/92) carries the "spool holds already-redacted envelopes" invariant; and `OBS-R048`'s allowlist posture (cited and central, §A.6) is *stronger* than R047's denylist enumeration because it rejects any non-allowlisted field to a minimal event. So no requirement is substantively unsatisfied.
- **Why it is still a finding:** the plan's own precedence rule (line 5) requires a MUST deviation to be argued; the capture-time→flusher-time move is unargued because R046 is no longer cited. And a PROG slice inheriting this plan has no general-path MUST stating "no unredacted data reaches any durable sink / the in-memory queue and spool never persist pre-redaction bytes" — round 0 stated it, round 1 dropped it.
- **Smallest change (absorb at C4, no rework round needed):** re-cite OBS-R046/R047/R054 in §A.7; add one MUST that redaction precedes every durable-sink write and that the bounded queue/spool never hold pre-redaction persisted bytes; state the capture-time→flusher-time deviation as argued (equal-work forces it; before-any-sink is preserved).
