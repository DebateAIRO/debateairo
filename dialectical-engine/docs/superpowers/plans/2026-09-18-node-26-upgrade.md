**Goal:** The project declares and runs on Node 26.8.2 (the newest stable release Homebrew ships on 2026-09-18; nodejs.org has 26.9.0 two days old and not yet bottled), every place that pinned 22.23.1 says the truth, the test runner is one that supports Node 26 (vitest 5.0.1 — its 4.1 line never copies Node's own `localStorage`/`sessionStorage` globals into the jsdom environment, which is why ~100 render tests failed on Node 25+), and every test failure the upgrade caused or unmasked is either fixed or named with its cause.
