# Account-flow release acceptance checklist

This checklist separates source evidence from target and human observations. The final acceptance record identifies each executed command and source scope. A checked local behavior is never an installed or real-provider certificate. Release remains blocked by the secondary2MiB bound, both uninstrumented600ms timing failures, phone-policy facts, target dependencies, compatible rollback artifact and final independent reviews. A passing instrumented timing diagnostic is not acceptance.

Capture nonsecret outcome/UTC time/source and runtime hashes with exact completed exit and teardown. Never retain tokens, passwords, biometrics, private mail aliases, grants, credentials or raw user records in acceptance artifacts. Actual target probes run only under their separately reviewed scope in deployment-handoff.md. No source test is marked as hardware, inbox, provider or Siteverify success.
