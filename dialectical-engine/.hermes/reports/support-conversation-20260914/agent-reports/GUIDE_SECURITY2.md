## Upgrades

- Define the guard as a small relation table: language × recovery subject (`password`, `reset code/token`, `recovery code/token`) × operation polarity × clause; and actor (`Support`, Romanian normalized forms, direct addressee) × actor position × account operation × navigation. Generate classifier and actual-route controls from the same reviewed table while keeping independent oracle assertions.
- Require every security case to assert five sinks together: classifier branch, answer-call count, exact deterministic text, persisted outcome/abuse class, and returned actions/sources. This catches the injection-accounting and fixed-text failures without a later special probe.
- Make the runner accept an explicit immutable matrix path and print that path, byte hash, case count, revision, and dependency-root hash before imports. Refuse basename-derived matrix selection. Name the log from the embedded matrix identity rather than the intended command.
- Add a preflight mode that validates authorized dependency links without running product imports. That separates custody failures from product failures and avoids spending the single heavy lease on launcher diagnosis.
- Treat a fix as complete only when the original examples and independently transformed neighbors pass. For bounded NLP guards, require at least synonym, normalization, clause-order, actor-position, and benign-pair transformations.
