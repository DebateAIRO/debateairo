## Finding 1 — review and ratification were one gate

The old loader treated `status=shipped` plus `ratified_by=V` as the only eligibility proof. That made an honest peer-reviewed preview impossible and encouraged copied authority metadata after factual edits. The upgrade separates exact-byte Sol editorial attestations from owner ratification, hashes the catalog and selected provenance into `kbVersion`, and leaves every changed/new draft blank-ratified. This needed one implementation pass; exact token and wall-clock cost are unavailable.

## Finding 2 — route truth existed as prose and partial allow-lists

The product map described 11 pages, conditional fragments and dynamic authority, while API and UI code held partial navigation lists. Re-deriving those facts is a recurring reading cost and invites drift. The upgrade is one browser-safe capability/action catalog with a closed action-id union and one resolver that requires trusted owner/public projections. A generated route-discovery fixture in the packet would have removed another source-reading pass.

## Finding 3 — version creation did not provide version identity at use time

The old loader produced a `kbVersion` but offered no immutable exact-version lookup. A session labeled A could therefore consume B after a live reload. The upgrade is a process-resident immutable lookup keyed only by the exact version. A mutation returning the current snapshot for every key failed the focused test, proving the regression check detects that class.

## Finding 4 — broad lexical matches can be noisy

The first implementation matched ordinary stop words such as “the” and “and,” selecting an unrelated creation article for an export query. The first GREEN diagnostic caught it at 46/47. Tracing the shared tokens led to a small bilingual stop-word filter; the focused context suite then passed 5/5. A packet-supplied lexical fixture with one relevant and one stop-word-only neighbor would have made this edge explicit from the start.

## What nearly went wrong

The initial RED stopped at missing module imports, so it established that the interfaces did not exist but did not prove their security assertions. The later snapshot and invalid-reviewer mutants supplied the meaningful refutation frames. I also nearly treated the plan's `reviews/manifest.json` as permission to create a real manifest, but the allowed-file contract omitted it and the owner forbade self-attestation. The implementation therefore defines and tests the manifest schema while leaving real attestation to the separate editorial seat.
