## Causes, evidence, and price

### Example closure was mistaken for class closure again

FIX4 closes every exact SECDELTA string, but the implementation encodes the same concepts as finite word and boundary lists. Small adjacent members reopen each class: `and also` and `so` escape negation scoping; `%61` escapes raw credential analysis; a third encoding escapes a two-pass decoder; four exact IDs escape a deny set; a quoted multiword value escapes a one-token capture.

**Price.** Four preparation corrections and four live demonstrations consumed repeated model calls and review cycles, yet one independent 35-case direct-import run found five sink-reaching blockers. Exact token usage and wall-clock duration are **UNAVAILABLE**.

**Upgrade.** Require every correction to state the invariant and the canonicalization boundary, then generate equivalence-class variants mechanically. Tests should vary coordinators, encoding depth, label/value shape, language inflection, and exact machine-token versus human label. A fix should fail if any equivalent member crosses the same sink.

### The screen has multiple inconsistent canonical views

Link and identifier checks inspect up to three views; credential relation analysis inspects only raw text; input redaction uses a separate normalized span map. This allowed an encoded credential term through while a double-encoded link was caught.

**Price.** Reviewers must reconstruct which policy sees which representation. That increases code-reading cost and makes green test counts poor evidence of composition.

**Upgrade.** Make canonical views a named product abstraction with explicit maximum depth and attach each check to the intended views. Emit a test matrix from that declaration. Keep original-span mapping only where redaction must rewrite original bytes.

### Human labels and machine IDs were conflated

The narrative-ID exception removes `forgot-password` because “Forgot password” is a valid human phrase. The hyphenated machine token is still unambiguously an ID; the safe spaced label already passes without an exception.

**Price.** The code designed to stop `start-debate` creates another exact-ID leak at the unresolved Forgot boundary. It also risks encouraging a correctness fix that weakens the security screen to improve live answer rate.

**Upgrade.** Keep exact machine identifiers closed and compare normalized prose against localized display labels separately. Navigation continues through structured server-resolved actions.

### Evidence correction was honest but late

LIVE4 initially serialized 12 fixed diagnostic fields where the packet allowed seven. The superseded bytes are preserved and the replacement is explicitly retrospective, makes no new request, and does not strengthen attribution. The product diagnostic itself remains secret-safe.

**Price.** One extra ticket, two evidence variants, a projection harness, and another reviewer comparison were needed. The original consumer remains historically noncompliant.

**Upgrade.** Generate the consumer schema directly from the checked packet and validate key equality before the first live request. Refuse capture when the producer projection differs instead of repairing evidence afterward.
