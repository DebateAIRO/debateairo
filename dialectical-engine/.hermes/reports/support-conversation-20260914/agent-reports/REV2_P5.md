# REV2_P5 self-report

> treat it like a murder case. I want to get a nice report on what can be done better. What we must upgrade. what repeatedly costed us tokens. how we can make the coding more efficient. How can we turn this into a one prompt machine even better.

## Cause

The remaining defect was lexical family ownership. The earlier parser listed a few Romanian surface forms independently in several credential categories. Ordinary plural `coduri` and the genitive/dative forms were missing, so a correctly split positive validation group had no credential object. The correction defines the bounded noun family once and composes every shipped Romanian code-credential category from it.

## What repeatedly cost time

Earlier reviews generated operation and delimiter classes but left the credential noun itself represented by examples. That let a new operation test pass while a neighboring noun form bypassed the relation. The fix/review cycle cost another author pass, two reviewer rechecks, a new freeze, and another exact-revision fixture.

The first pass-5 probe attempt also demonstrated a smaller harness cost: changing both the credential language and the routing sentence at once made the synthetic request miss the English article route and stop before the model call. Preserving that failure made the cause explicit. The rerun changed only the routing prefix and retained the Romanian credential and all sink assertions.

## Upgrade for a one-prompt workflow

1. Extract lexical families from every shipped localized label before writing a security matcher. For a noun, generate singular, definite, plural, and genitive/dative forms as one table.
2. Cross that table with operation polarity, reference form, envelope, and actual sink. A local relation test is incomplete until its subject and object vocabularies are generated too.
3. Pair credential-qualified “code” cases with postal, error, display, and profile controls so the safe boundary is reviewable.
4. Freeze a known routing prefix separately from the payload under test. Changing both in one fixture hides whether a failure occurred in routing or screening.
5. Keep one narrow correction probe and carry forward unrelated PASS evidence. This pass needed 10 hostile policy rows, 6 safe rows, and 6 service rows rather than another 25-file execution.
6. Require the packet to name the linguistic family, expected credential kind, expected predicate, and each sink. This makes a single prompt generate the matrix mechanically.
